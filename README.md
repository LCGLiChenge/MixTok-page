# MixTok project page

Static, dependency-free project page inspired by the FlashAR project page.

- [Project page](https://lcglichenge.github.io/MixTok-page/)
- [Paper on arXiv](https://arxiv.org/abs/2610.13181)
- [Paper PDF](https://arxiv.org/pdf/2610.13181)

## Preview

Run from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.

## Publication

MixTok is available as [arXiv:2610.13181](https://arxiv.org/abs/2610.13181), submitted on October 9, 2026. The project page includes the authors and affiliations, an active Paper link, and the arXiv BibTeX citation.

## Maintenance

- Keep the paper link and BibTeX in `index.html` synchronized with the arXiv record.
- Confirm the GitHub and Hugging Face repositories remain publicly accessible.
- Recheck reported metrics against the manuscript when updating results.

The page uses Google Fonts and links to arXiv, author profiles, GitHub, Hugging Face, FlashAR, and Nerfies.
