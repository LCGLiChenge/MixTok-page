# MixTok project page

Static, dependency-free project page inspired by the FlashAR project page.

## Preview

Run from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.

## Before publication

1. Replace the author placeholder in `index.html` with the final author and affiliation block.
2. Replace the draft BibTeX author field.
3. Confirm the GitHub and Hugging Face repositories are publicly accessible.
4. Point the disabled Paper button to the public arXiv version when available.
5. Recheck all reported metrics against the final manuscript.

The page is self-contained apart from the GitHub, Hugging Face, and FlashAR links.
